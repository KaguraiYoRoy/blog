# 1. 数据统计
本网站使用自建的 **Umami** 统计服务。这是一项隐私优先的分析工具，它：

* **不使用 Cookie：** 不会在您的浏览器中存储任何追踪文件。
* **匿名化：** 所有的访问数据都是匿名汇总的，我们无法通过统计数据识别您的个人身份。
* **数据主权：** 统计数据存储在我们受控的私人服务器上，不会泄露给任何第三方。

# 2. 评论功能
当您在本站发表评论时，我们会收集您在评论表单中填写的文字以及以下数据：

* **个人信息：** 包括您提供的昵称、电子邮箱和个人网站（如有）。
* **技术信息：** 为了防止垃圾评论和恶意攻击，我们会记录您的 **IP 地址**和浏览器用户代理（User Agent）。
* **存储时间：** 评论及其元数据将无限期保留，直到您要求我们删除。

# 3. 您的权利
如果您在本站留下了评论，您可以请求我们提供您个人数据的导出文件，或请求我们删除这些数据。

# 隐私政策

最后更新：2026-11-01

## 1. 访问统计

本网站使用自建的 **Umami** 服务，了解页面浏览量、访问会话和文章的阅读情况。统计脚本由 `analytics.iyoroy.cn` 提供，数据发送至该服务。

统计信息包括页面地址、标题、来源页面、浏览器语言、屏幕尺寸，以及根据访问请求生成的浏览器、设备类型和大致地区等信息。页面地址可能包含查询参数，请不要在网址中填写密码或其他敏感信息。

Umami 不使用统计 Cookie，浏览文章也不要求提供姓名、邮箱或账号。这些统计用于了解本站的访问情况，不用于跨站广告追踪。

## 2. 浏览器本地存储

网站使用浏览器的 `localStorage` 保存亮暗模式和主题色偏好，以便下次访问时沿用。这些设置保存在你的浏览器中，不会作为 Umami 统计数据发送。你可以通过浏览器的站点数据设置清除它们。

## 3. 托管服务与外部链接

网站通过 GitHub Pages 和境内服务器提供静态页面。托管服务及相关网络服务在处理请求、排查故障和提供安全防护时，可能记录 IP 地址、请求时间、页面地址和浏览器标识等日志；这些日志与 Umami 统计分别处理，保留方式取决于相应服务的配置和政策。

文章可能包含外部链接或资源。访问其他网站，或由浏览器加载外部资源时，相应服务会收到访问请求，并适用其自己的隐私政策。

## 4. 联系方式

对本站的数据处理有疑问，或希望查询、更正、删除你主动提供的个人信息，请联系 [i@iyoroy.cn](mailto:i@iyoroy.cn)，并说明相关页面或信息，以便核实和处理。
